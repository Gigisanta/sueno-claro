# SleepLike launch, September 2026

This document supersedes the earlier affiliate, native app and no-analytics roadmap for the approved web rework. No accounts, backend, subscription or microphone access were added.

## Architecture and local verification

- `lib/content/pages.ts`: 24 typed pages (six tools, eight guides, ten institutional pages), paired EN/ES. Root remains English; language root layouts emit the correct document language.
- `lib/sleep`: deterministic calculation, explicit reference instant, local dates, DST ambiguity choices, UTC calendar events. Short naps represent 20 minutes **in bed**, not 20 guaranteed minutes asleep.
- `components/CalculatorShell.tsx`: inputs remain local. New share links use a fragment. Legacy query links are read once, then removed before third parties. Shared sleep-now links deliberately calculate a fresh instant on the recipient's device.
- `components/PrivacyProvider.tsx`: optional aggregate analytics. Ads require the configured certified Google CMP and positive consent. Rejection, CMP failure and offline mode keep ads off. A referrer containing query/fragment disables third parties for that document; subsequent navigation sends no referrer.
- `scripts/postbuild.mjs`: generates a release-hashed service worker with complete HTML/chunk precache. Updates wait for old tabs to close; no forced activation mixing versions. Neither personal queries nor third-party/analytics traffic are cached.
- `scripts/serve.mjs`: compressed local static server reflecting security headers and the retired calculator redirect.

Run `npm ci`, `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e`. E2E covers Chromium and WebKit, mobile and desktop. WebKit's automation offline reload produces an engine internal error; WebKit verifies cached shell/control and calculation after going offline in the current document. Chromium additionally verifies a full offline reload. Do not report WebKit offline reload as verified.

Advertising stays disabled until ALL are true:

1. Owner information/payment details completed with real data; Google reports site approval Ready.
2. Root ads.txt is publicly available and accepted by AdSense.
3. Manual result/article slots configured. Auto Ads, Auto optimize, anchors and vignettes off.
4. Certified CMP published for this publisher, EN/ES, all visitors; positive consent before ads; non-personalized ads selected.
5. CSP/network validation with the real CMP and units passes. Expand only observed required origins. Static CSP currently keeps ads blocked while account approval is pending.
6. Browser checks confirm rejection, error, acceptance, revocation, ad blocking, no ad before result, maximum requests and CLS ≤0.1 under real advertising.
7. Set public env values from `.env.example`, then `NEXT_PUBLIC_ADS_APPROVED=true` and rebuild.

The page limits new requests to one result unit and two article units per document. Empty or blocked units never impersonate a sponsor. Revocation removes units and prevents new requests; already executed third-party code cannot be undone retroactively.

Analytics events are `calculation_completed`, `share`, `reminder_download`, with only `mode` and `language`. No time, date, latency or result is sent. Pageviews are URL-sanitized. Opt-out cancels later events through the registered beforeSend callback. Vercel/hosting necessarily receives the initial URL when someone opens an old query link; fragments do not travel in the HTTP request.
